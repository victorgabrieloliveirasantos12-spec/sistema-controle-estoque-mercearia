# Sistema de Controle de Estoque e Vendas

Sistema Web para auxiliar pequenas mercearias no cadastro de produtos,
controle de estoque e registro de vendas.

## Objetivo

Facilitar o gerenciamento dos produtos e reduzir erros no controle de estoque.

## Funcionalidades

- Cadastro de produtos.
- Consulta de estoque.
- Registro de vendas.
- Alertas de estoque mínimo.

## Tecnologias

- Python
- Flask
- PostgreSQL
- Bootstrap

## Como executar

Instale as dependências:

pip install -r requirements.txt

Inicie o sistema:

python app.py

## Testes

Execute os testes automatizados:

pytest
